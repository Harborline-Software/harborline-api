# Security

## Support

Harborline is pre-release. There are no supported installs and no security fixes are backported.

## Reporting

Report a suspected vulnerability privately: use GitHub's private vulnerability reporting on this repository if it is enabled. Otherwise, open an issue titled "security contact request" with no details; a maintainer will reply with a private channel.

Do not include credentials, private data, or exploit details in a public issue.

## Response

We will acknowledge reports within seven days, confirm or decline within thirty, and credit the reporter in the fix unless asked not to.

## Scope

Code in this repository. Report third-party dependency vulnerabilities to their maintainers; tell us too if Harborline's use of them makes the issue reachable.
