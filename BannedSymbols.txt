; ADR 0013 enforcement gate — BannedApiAnalyzers (RS0030).
; Wiring lives in Directory.Build.props (_HarborlineBannedApiTarget) + Directory.Build.targets.
; Applies to every packable, non-test, non-analyzer project. Tests are exempt by design.
;
; Format: <docid>;<message>.  T:=type  M:=method  P:=property  F:=field
;
; ADMISSION RULE FOR THIS FILE: every entry below has ZERO current production call sites.
; This file is a fence against the FIRST use, not a burn-down list. Anything with live call
; sites belongs in a CA rule (see AnalysisLevel in Directory.Build.props) or an arch test,
; where the existing uses can be counted and allow-listed, not in here where it just fails
; the build for everyone. Verify a candidate is at zero before adding it.
;
; NOT here, on purpose:
;   - DateTime.Now / UtcNow / TimeProvider.System — already fenced with a counted allow-list by
;     apps/local-node-host/tests/ArchTests/KernelClockArchTests.cs (ticket 216). One fence only.
;   - string.ToLower/ToUpper, CultureInfo.CurrentCulture — 130+ live sites; CA1304/CA1305/
;     CA1307/CA1310 now surface these as warnings. Burn down there, then reconsider.
;   - System.Random — 2 live sites (foundation-events/EventId.cs, kernel-sync GossipDaemon
;     jitter). Both non-crypto, but EventId identity from Random.Shared is worth a look.
;   - Environment.Exit, GetAwaiter().GetResult() — deliberate live uses in the host and in
;     sync-bridge seams. Not defects.
