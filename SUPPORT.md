# Support

Use this repository's [GitHub Issues](https://github.com/Harborline-Software/harborline-api/issues) for non-sensitive usage questions and bug reports about Harborline API.

Search open and closed issues before opening a new one.

## Usage questions

Open an issue and identify it as a usage question.

Explain what you are trying to do, the Harborline release or commit you are using, where you obtained it, and the documentation you already checked.

## Bug reports

Open an issue with enough sanitized context for a maintainer to understand and reproduce the problem:

- Harborline release or commit and installation source.
- Operating system and version, host or deployment type, and other relevant environment details.
- Minimal steps that reproduce the problem.
- Expected and observed behavior.
- Exact error text and the smallest relevant log excerpt, with secrets and private data removed.
- A minimal sample when practical, with proprietary or personal data replaced.

Do not include credentials, access tokens, personal or customer data, private repository content, complete configuration files, data exports, or exploit details.

Opening an issue does not establish a response-time, fix, or release commitment.

## Sensitive disclosures

For a suspected vulnerability or other sensitive disclosure, follow [SECURITY.md](SECURITY.md) instead of describing it in a support issue.

## Contributions

Outside contributions and pull requests are not currently accepted; see [CONTRIBUTING.md](CONTRIBUTING.md).
