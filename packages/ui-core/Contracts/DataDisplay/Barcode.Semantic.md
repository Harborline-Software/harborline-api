## 1. Component purpose

**Barcode** — renders an SVG visual representation of a linear barcode for a given string value. Like QRCode, uses a deterministic pseudo-bar pattern rather than a standards-conformant encoding. The rendered barcode is **not scannable** by real barcode readers.

---

## 2. Props

```typescript
type BarcodeType = 'code128' | 'code39' | 'ean8' | 'ean13' | 'upca' | 'upce' | 'jan13' | 'jan8'

interface BarcodeProps {
  value: string                          // required; the string to encode
  type?: BarcodeType                     // default: 'code128'; affects visual pattern only
  width?: number | string                // default: 200 (pixels)
  height?: number | string               // default: 80 (pixels)
  color?: string                         // default: 'currentColor'
  background?: string                    // default: 'transparent'
  label?: boolean | { visible: boolean; color?: string; font?: string }
                                         // default: true; shows value text below bars
  checksum?: boolean                     // reserved; M1 not used
  aria-label?: string                    // overrides the default "Barcode: {value}" AT label; use when value is sensitive (see Barcode.Accessibility §2)
  className?: string
}
```

---

## 3. M1 rendering limitation

Bar widths are generated by a deterministic hash of `value + type`. The output is a visually plausible barcode but is **not standards-conformant** and cannot be scanned.

---

## 4. Label

When `label=true` or `label.visible !== false`, the `value` string is rendered as an SVG `<text>` element centered below the bars. `showLabel` reduces bar height to `height - 16` to make room.
