# Security

Harborline is pre-release. There are no supported installs and no security fixes are backported.

**Reporting.** Report a suspected vulnerability privately: use GitHub's private vulnerability
reporting on this repository if it is enabled, otherwise open an issue titled "security contact
request" with no details and a maintainer will reply with a private channel. Do not put
credentials, private data or exploit details in a public issue.

**What we will do.** Acknowledge within seven days, confirm or decline within thirty, and credit
the reporter in the fix unless asked not to.

**Scope.** Code in this repository. Third-party dependencies go to their own maintainers; tell us
too if Harborline's use of them is what makes the issue reachable.
