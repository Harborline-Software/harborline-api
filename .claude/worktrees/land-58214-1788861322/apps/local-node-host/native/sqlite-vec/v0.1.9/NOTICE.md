# sqlite-vec native notice

This directory redistributes the official sqlite-vec v0.1.9 loadable-extension binaries for
`win-x64` and `osx-arm64` from <https://github.com/asg017/sqlite-vec/releases/tag/v0.1.9>.

sqlite-vec is Copyright (c) 2024 Alex Garcia and is dual-licensed under MIT or Apache-2.0.
Harborline Software redistributes these binaries under the MIT option; see `LICENSE-MIT`.

`manifest.json` records the upstream release archive and extracted-library SHA-256 digests. The
build independently verifies the library digests before staging a matching RID payload.
