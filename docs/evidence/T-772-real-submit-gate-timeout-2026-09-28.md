# T-772 real submit-gate timeout propagation, Stryker pending

The public seam is the production `IFormEngine.SaveWithReceiptAsync` composed by `AddTestNodeForms` with a published form and a compiling `restrict.active` validation rule. The new test first proves the rule validates normally, then arms a test clock to cancel the request token at the graph's clock read, after authorization and definition lookup. `SaveWithReceiptAsync` propagates the real graph's `RuleEngineTimeoutException` instead of returning a validation verdict or reaching persistence. The first attempt with an already-cancelled token failed at the authorization gate with `OperationCanceledException` and was test setup failure, not a useful behavioral red. The corrected focused test passed; the affected host test project passed 4,524 tests with 22 skipped. No production code changed.

Both selected the one public test, but Stryker's safe mode excluded `SubmitValidationGate.Evaluate` after instrumentation compile errors elsewhere in that method; the call-site span produced no mutation operators.
